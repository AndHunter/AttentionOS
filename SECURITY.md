# Security Policy

AttentionOS is a local-first desktop app that records behavioral telemetry, so security and privacy reports matter.

## Supported Version

Security reports should target the current `main` branch and the latest published release.

## Reporting

Please do not open a public issue with secrets, private telemetry, database exports or screenshots that contain personal data.

Use GitHub private vulnerability reporting if it is enabled for this repository. If it is not enabled yet, contact the repository owner through a private channel first and share only the minimum reproduction details needed to verify the issue.

## Privacy Expectations

Reports should never include real user databases, logs, exported ML datasets or personal model files unless the owner explicitly asks for a sanitized sample.

AttentionOS must not collect typed text, raw keystrokes, screenshots, clipboard content, microphone, camera or document contents.
